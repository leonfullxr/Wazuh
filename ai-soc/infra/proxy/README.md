# Qualification proxy reference

The TLS front end uses stunnel for the configured `https://proxy-host:443`
URL and forwards decrypted proxy requests over task-local loopback to Squid.
Squid's `ssl-bump` listener peeks at each CONNECT tunnel's ClientHello and
splices TLS unchanged only when the CONNECT hostname and the actual SNI are
the same DNS name and the hostname appears in the generated allowlist. Its
helper rejects absent SNI and name mismatches; numeric IPv4 and IPv6
authorities are denied. Squid forwards permitted requests directly to origins.

Install [stunnel-qualification.conf](stunnel-qualification.conf),
[squid-qualification.conf](squid-qualification.conf), and
[connect-sni-match.sh](connect-sni-match.sh) with the listener certificate,
private key, and hostname file generated by `terraform output -json
qualification_proxy_required_hosts`. The helper must be readable by Squid and
`/bin/sh` must exist in its runtime image. Do not expose Squid's loopback port
outside the task network namespace.

This reference enforces destination identity at CONNECT/SNI time. Because TLS
is spliced unchanged, it does not inspect encrypted HTTP headers or verify
that an HTTPS `Host` header agrees with SNI. It also does not validate the
origin certificate; the TLS client remains responsible for certificate
validation. Those limits matter for shared-hosting front ends that route
requests by encrypted HTTP `Host` headers.

## Offline behavioral regression

`make bootstrap` prepares the digest-pinned Squid/OpenSSL image and Python
fixture image. `make test-security` then runs
`tests/security/infra/test_qualification_proxy_config.py` against the shipped
Squid configuration. The test creates an internal-only Docker network, a
local TLS origin with a temporary test certificate, and exercises permitted
and refused CONNECT/SNI combinations. Test containers use `--pull=never`; a
missing prepared image fails with an actionable message. No AWS or external
network is contacted.

Squid's `url_regex` evaluates the complete URL and its server-name ACL may use
the CONNECT target when SNI is absent. The external helper therefore compares
Squid's CONNECT URI with the separately reported ClientHello SNI. References
checked 2026-10-07:
