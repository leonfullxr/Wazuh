Agent enrollment

  registration  {{ include "wazuh.managerServiceName" . }}.{{ .Release.Namespace }}.svc:{{ .Values.service.master.registrationPort }}
{{- if and (eq .Values.service.events.type "ClusterIP") (not .Values.tcpServices.enabled) }}

  Both services are ClusterIP, so external agents cannot reach them yet. Set
  service.events.type and service.master.type to LoadBalancer, or enable
  tcpServices and expose 1514/1515 on your ingress controller. Never put these
  ports behind an HTTP Ingress or an ALB — the proxy treats the agent stream as
  HTTP and resets it.
{{- end }}

Rotating indexer credentials later
  The indexer reads internal_users.yml only while bootstrapping an empty
  cluster. Editing a password in values.yaml alone does nothing afterwards;
  set indexer.security.runSecurityadmin=true so the post-upgrade Job applies
  the change to the running cluster.
